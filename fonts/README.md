# Fonts

This directory contains the fonts loaded by `nbubachelor.cls` with project-relative paths.

Bundled families:

- `FandolSong-Regular.otf`, `FandolSong-Bold.otf`: Songti-compatible Chinese body font.
- `FandolHei-Regular.otf`, `FandolHei-Bold.otf`: Heiti-compatible Chinese heading font.
- `FandolKai-Regular.otf`: Kaiti-compatible Chinese abstract and cover font.
- `FandolFang-Regular.otf`: Fangsong-compatible fallback font.
- `texgyretermes-*.otf`: Times-compatible Latin font family.
- `texgyretermes-math.otf`, `latinmodern-math.otf`: math fonts.

The files were copied from the local TeX Live distribution so that the template can be compiled after copying the whole project directory. When redistributing the template, keep the font license requirements in mind.
