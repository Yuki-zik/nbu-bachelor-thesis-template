# Figures

Place thesis-specific figures in this directory. The template keeps the Ningbo University cover header here because this project is an NBU thesis template.

- `figures/nbu_cover_header.png`: Ningbo University cover header used by `main.tex`.
- `figures/ningbo_university_gate.jpg`: real illustration used as Figure 1 in Chapter 1. Source: [Wikimedia Commons, `File:Ningbo University 2018-04-09 01.jpg`](https://commons.wikimedia.org/wiki/File:Ningbo_University_2018-04-09_01.jpg); description: 宁波大学正门; author: Nbfreeh; license: [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/).
- `figures/chapter1-framework.png`: optional figures used by Chapter 1.
- `figures/generated/`: generated figures that can be recreated from data or scripts.

Avoid storing source CSV/JSON data here. Put source data under a paper-local `data/` directory if the figure is generated from experiment values.
